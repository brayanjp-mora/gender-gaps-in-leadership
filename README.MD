# Gender Gaps in Leadership Across Countries

A cross country visualization exploring the gaps in leadership across countries available within the UNSDG 5.5.2 indicator (Proportion of women in managerial positions)

## Data Sources

| Source | Variable |
| ---| --- |
| [UN Global SDG Database](https://unstats.un.org/sdgs/dataportal) | Goal 5: Achieve gender equality and empower all women and girls. Indicator 5.5.2, Proportion of women in managerial positions |

## Outputs

**choropleth map** — A global choropleth map using continuous color shading to visualize the proportion of women in managerial positions across different countries
